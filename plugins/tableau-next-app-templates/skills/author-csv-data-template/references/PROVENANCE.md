# Template Pack — provenance

Generated by `tools/pack/build-template-pack.sh` (source project only) from the aftest project's
git-tracked files (+ named skills from ~/.claude/skills).

**Excluded for safety:** private keys/certs, real `.env` files, git plumbing.
Any `metadata/orgInfo.json` is **redacted** (org id / username / instance URL
blanked). See `tools/dist/dist-scrub.config` (source project only) in the source project for exact rules.

---

Repackaged into the `author-csv-data-template` skill. Reference templates under
`references/` carry **JSON only** — the sample CSVs and preview images were omitted for
size, so they are for reading file shapes, not for deploying as-is. To run `CSV_Example`
or `superstore_demo_template` end to end, get the full aftest template pack.
